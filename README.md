# 30 Days of UI

One UI element a day, designed and built in code — free to use in your own projects.

![30 Days of UI](https://img.shields.io/badge/30%20Days%20of%20UI-Day%208%2F30-blue)
![License: MIT](https://img.shields.io/badge/License-MIT-green)
![No build step](https://img.shields.io/badge/Build-None%20needed-lightgrey)

Every day ships as **one self-contained HTML file**. No framework, no build step, no install — open it in a browser, copy the code, remix it. The same component also lives in `react/`, `vue/`, and `angular/` — same design, same colors, same copy, rebuilt for your framework.

> Every component ships in four versions — plain HTML/CSS, React, Vue, and Angular. Pick your stack's folder, copy the code, remix it.

## How to use it

1. Open any `day-*.html` file in a browser — it just works. Or grab the same component from `react/`, `vue/`, or `angular/`.
2. Copy the code into your project and make it yours.
3. If you ship something with it, a shout-out is appreciated, not required.

All numbers inside the designs (credits, prices, follower counts) are concept data for the demo — swap in your own.
